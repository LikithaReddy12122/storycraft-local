# StoryCraft Local 🏯✨

> **Decentralized AI-Powered Tourism & Cultural Merchant Platform**  
> *Connecting Mindful Travelers with Living Culture — Zero Crowds, Zero Intermediary Fees, Zero Excluded Artisans.*

## Live Prototype Features
1. **Interactive Anti-Congestion Dispersal Map:** Real-time crowd detection with instant "Smart Pivot" dynamic vouchers.
2. **Spatial Audio Companion:** Proximity-based cultural narratives with interactive voice Q&A.
3. **60-Second Voice-to-Storefront Onboarding:** Voice note ingestion for digitally excluded artisans and food stalls.
4. **Multimodal Bill & Scam Auditor:** Camera scanner that flags unauthorized cover charges under local consumer laws.
5. **In-Room Hotel AI Concierge:** White-label QR portal for independent guesthouses.

## Deploying to Vercel

### Option 1: GitHub Integration (Recommended)
1. Push this folder to a new GitHub repository.
2. Go to [vercel.com/new](https://vercel.com/new).
3. Select your repository and click **Deploy**.

### Option 2: Vercel CLI
```bash
npm install -g vercel
vercel login
vercel --prod
```
